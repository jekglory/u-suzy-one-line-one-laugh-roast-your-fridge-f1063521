One line roasting a fridge: a smart fridge that spends its budget
surveilling the milk with a camera, yet stays blind to the month-old
leftovers quietly plotting against its owner inside it.

## Run it

```sh
python3 main.py
```

Writes the single line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`). Pure standard library, deterministic:
two runs produce byte-identical output.
